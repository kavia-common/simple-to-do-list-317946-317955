# todo_frontend

React single-page app for the Simple To‑Do List.

## Run (dev)

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Features

- Add tasks (Enter / Add button)
- Inline edit with Save/Cancel (Enter saves, Esc cancels)
- Mark complete with checkbox
- Delete tasks
- Client-side filters: All / Active / Completed
- Persisted in localStorage under key `todo_tasks`
